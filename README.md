# Sharoob VPN

Free VPN tool for Android Termux.

## Installation

Copy and paste this command in Termux:

    curl -fsSL https://raw.githubusercontent.com/sawsan180/sharoob-vpn/main/install.sh | bash

## Usage

Run:

    sharoob

Interactive menu:
- 1 - Connect / Disconnect
- 2 - Status
- 3 - View Logs
- 4 - Settings
- 5 - Help
- 6 - Change language
- 7 - Exit

## Features

- Pre-flight system checks
- Auto-retry connection (3 attempts)
- Auto-update on each run
- Bilingual (English / Arabic)
- Optional Termux:API notifications

## Requirements

- Termux (from F-Droid or GitHub)
- Clash for Android
- Internet connection
